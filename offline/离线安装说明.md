# MindCanvas 离线镜像包（air-gapped）

完全离线安装，**不需要任何外网**（镜像、依赖已全部打进 `mindcanvas-image.tar.gz`）。
架构：**linux/amd64**。前置：目标机已装 Docker 引擎（含 `docker compose` 插件）。

## 内容
- `mindcanvas-image.tar.gz` —— 完整镜像（含 node:22 运行时 + 应用 + ws 依赖）
- `docker-compose.offline.yml` —— 不构建、直接用已载入镜像
- `.env.example` —— 配置模板
- `install.sh` —— 一键：load 镜像 → 生成 .env → 起服务
- `DEPLOY.md` / `README.md` —— 部署文档 / 使用说明

## 安装（3 步）
```bash
tar xzf mindcanvas-offline-amd64.tgz && cd mindcanvas-offline
vi .env.example   # 可选：先按需改，install.sh 会据此生成 .env
./install.sh
```
或手动：
```bash
docker load -i mindcanvas-image.tar.gz
cp .env.example .env && vi .env        # 改密码/端口；Key 可留空
docker compose -f docker-compose.offline.yml up -d
```

## 启动后
- 访问 `http://<本机IP>:<HOST_PORT>/admin`，用 .env 里的管理员账号登录
- 在 /admin 配置综合引擎 Key（持久化到卷；镜像 keyless）—— 若目标机能访问 LLM 端点
- 尽快修改默认 admin / speaker 密码

## 没有 Docker 引擎？
目标机若连 Docker 都没装，需另行离线安装 Docker（如 `apt-get install docker.io` 的离线 deb 包，或对方内网源）。本包只负责应用本身。详见 DEPLOY.md §6。
